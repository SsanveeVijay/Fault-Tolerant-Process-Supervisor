# Fault-Tolerant Process Supervisor

## Operating Systems Lab Project

A fault-tolerant process supervisor that manages and monitors multiple worker processes.

The supervisor detects when a worker process terminates unexpectedly, records the failure, and automatically creates a replacement worker.

## OS Concepts

- Process creation using fork()
- Program execution using exec()
- Process monitoring using waitpid()
- Process IDs and process states
- Parent-child process relationships
- Process termination and recovery
- Failure logging
